# Employee-Attendance-Monthly-Salary-Tracker

Welcome to the Employee Attendance and Monthly Salary Tracker project! This repository contains a ready-to-use, professional Excel workbook designed to help small businesses, HR teams, and managers effortlessly track daily staff attendance and compute monthly payroll.

# About the Project

Managing attendance records and calculating monthly salaries manually can be time-consuming and prone to human error. This project provides a clean, structured, and automated Excel solution built within a single file using a two-sheet system. By separating configuration settings from daily operations, the workbook remains organized, easy to maintain, and fully scalable as your team grows.

# How the Workbook is Structured

The Excel file is divided into two dedicated sheets that work together seamlessly:

Sheet 1: Calendar & Attendance Tracker
This is your main daily dashboard. It features a monthly calendar grid where managers can record daily attendance using simple status codes. It automatically aggregates total present days, half days, paid leaves, absences, and holidays to compute each employee's net monthly salary in real-time.

Sheet 2: Settings
This acts as the administrative backend of the workbook. It stores your master employee directory, department lists, designation details, daily salary rates, and reference tables for attendance codes. The main tracker sheet pulls its information and data validation dropdowns directly from here, ensuring consistency across your records.

# Key Features

Automated Payroll Calculations: Instantly determines monthly earnings based on effective payable days and daily rates.

Streamlined Daily Tracking: Uses standardized attendance codes (such as Present, Absent, Half Day, and Paid Leave) to keep records uniform.

Dynamic References: Employee information flows automatically from the Settings master list into the attendance calendar using reference links.

Clear Visual Layout: Designed with professional formatting to make monthly reviews and audits quick and straightforward.

# Getting Started

Download or clone this repository to your local computer.

Open the Excel workbook in Microsoft Excel or Google Sheets.

Navigate to the Settings sheet and update your employee names, IDs, departments, and daily pay rates.

Go to the Calendar sheet to begin recording daily attendance and viewing automated salary summaries for the month.
